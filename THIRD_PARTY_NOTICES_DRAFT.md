# Third-party notices — draft

This repository contains no raw medical images, third-party source archives,
model weights, checkpoints, rendered prediction images, or masks. It does include
numeric evaluation outputs and receipts for three baseline render sets.

First-party evaluator and `benchmark_integrity` code remain licence-pending.
The locked installation uses NumPy 2.3.5 and Pillow 12.3.0 at runtime, and
setuptools 82.0.1 for packaging. Installed package metadata identifies NumPy's
core licence as BSD-3-Clause, Pillow as MIT-CMU, and setuptools as MIT. NumPy
binary distributions also include separately licensed components; the complete
notices shipped with each dependency remain authoritative. Dependency code and
wheels are not vendored here. This draft is not a complete public-release review.

The author manuscript and reading copy are included under `paper/`; their versions
and provenance are documented in `paper/README.md`. No third-party paper PDFs are
bundled. The author conference video and English captions are included under
`presentation/`. Their inclusion does not grant a licence to reuse them.
